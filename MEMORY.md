# MEMORY.md — Project Memory Log

A running journal of decisions, pinned versions, gotchas, and lessons learned as the course progresses. This is expected to change constantly — unlike [`PLAN.md`](PLAN.md) (fixed intentions) or [`Progress.md`](Progress.md) (checkbox tracker), this file is the *why* and *what we learned* behind the work.

Add entries as they happen — don't batch them up from memory later, details get lost.

## How to use this file

- Add a dated entry under the relevant phase when you make a non-obvious decision, hit a gotcha worth remembering, pin a tool/library version, or leave a question open for later.
- Keep entries short — a bullet or two, not paragraphs.
- Never delete history here; if a decision was later reversed, add a new entry noting the reversal and link back to the old one.
