The idea of this repository is to journal a journey of learning multiple different technologies and programming practices.

I want to learn the basics and concepts of
- Responsive Web Design
- JavaScript/Typescript
- Front-End Development & Libraries
- Python
- Relational Databases
- Back-End Development and APIs
- ELT and ETL processes
- ML Techniques

The plan is to develop a very simple product that include all of these concepts and plan a course building it step by step from scratch.

The app is gonna be a mini game that combines ingredients to create potions in a D&D style.

To learn ETL and ELT processes - 
We want to digest the raw data I have uploaded into the databases planned and be able to update user stats and adding new potions/ingredients later. Add associated images.

To learn databases we create 3 DBs - 
1 for ingredients, 1 for final possible potions, 1 for the user itself storing their stats.
We'll need to figure out how each database relates to each other, like which ingredients are needed for a potion. The difficulty of a poition related to user skill etc.

To learn ML Techniques - 
I want to create a model that predicts success or failure chance when creating a potion with the choice of ingredients and user level.

To learn Python, API and Backend -
I want to create a server that calculates the potion creation using formulas and predict success or add or remove entries, update user stats etc.

To learn frontend, javascript and web-design - 
We create the mini-game which interacts with the backend to retrieve data and other things.
